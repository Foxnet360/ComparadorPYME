# template-aware-unified-prompt Specification

## Purpose

Inject insurer-specific template hints from `templateRegistryService` into the unified comparison prompt for recognized insurers (BBVA, SBS, MAPFRE), while keeping a generic prompt for all others.

## Requirements

### Requirement: Template matching before LLM call

The system SHALL call `templateRegistryService.matchTemplate({ text, pages, domain: 'pyme' })` for each uploaded PDF before building the unified prompt in `unifiedComparisonEngine.compare`.

#### Scenario: BBVA template matches

- GIVEN a PDF whose text and layout markers match the BBVA template
- WHEN `matchTemplate` returns `templateId: 'bbva-pyme-v1'` and confidence >= 90
- THEN the system SHALL mark the quote as insurer `BBVA` and use the BBVA prompt addon.

#### Scenario: No template matches

- GIVEN a PDF whose text does not match any template
- WHEN `matchTemplate` returns `templateId: null`
- THEN the system SHALL use the generic V2 prompt without insurer-specific hints.

### Requirement: Prompt hint injection

For matched BBVA, SBS, or MAPFRE templates, the system SHALL append the matched template's `promptAddon` to the prompt generated by `comparisonPromptBuilder.buildV2ComparisonPrompt()`.

#### Scenario: BBVA hint added

- GIVEN a BBVA template match with `promptAddon` containing deductible instructions
- WHEN `buildV2ComparisonPrompt` is called
- THEN the returned prompt SHALL include the generic V2 instructions followed by the BBVA addon.

#### Scenario: Multiple quotes with different insurers

- GIVEN one BBVA PDF and one SBS PDF
- WHEN the prompt is built
- THEN the prompt SHALL include both BBVA and SBS addons, each labeled by insurer.

### Requirement: Generic fallback for uncovered insurers

Insurers without a matched template SHALL receive the standard V2 prompt, and the system SHALL NOT inject any template addon or hallucinate insurer-specific instructions.

#### Scenario: Generic insurer receives generic prompt

- GIVEN a PDF from an insurer without a registry entry
- WHEN the prompt is built
- THEN the prompt SHALL equal the generic `buildV2ComparisonPrompt` output
- AND no insurer addon SHALL be present.

### Requirement: Cost and latency guardrail

The system SHALL measure per-insurer token count and latency for template-hint requests and disable hints for an insurer when the p95 increase exceeds 15% over the no-hint baseline.

#### Scenario: Token cost exceeds guardrail

- GIVEN `useUnifiedTemplateHintsBbva` is enabled and baseline cost is 1000 tokens
- WHEN p95 cost with BBVA hints exceeds 1150 tokens
- THEN the system SHALL set `useUnifiedTemplateHintsBbva=false` for subsequent requests
- AND the next BBVA request SHALL use the generic prompt.

#### Scenario: Latency exceeds guardrail

- GIVEN baseline p95 latency without hints is 8000ms
- WHEN p95 latency with BBVA hints exceeds 9200ms
- THEN the system SHALL disable BBVA hints
- AND it SHALL log the disable reason.
