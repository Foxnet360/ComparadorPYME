# Spec: Saneamiento de Integridad, Eliminación de Código Muerto y Unificación Arquitectónica

## Requirements

### Requirement 1: Centralización Única de Constantes Legales (SMMLV y UVT)
`server/src/config/env.ts` and `server/src/config/domainConstants.ts` MUST:
- Expose `getDomainConstants(domain)` and `resolveValueToCOP(val, unit)` backed strictly by `process.env.SMMLV_VALUE` (default: `1423500` for 2025) and `process.env.UVT_VALUE` (default: `49799`).
- Forbid hardcoded string or integer literals `1300000` / `1423500` across services, parsers, and test suites.
- Align `server/src/data/thesaurus.json` and domain taxonomy bundles to reference the unified constants.

### Requirement 2: Unificación de Modelo Gemini y Eliminación de Defaults Divergentes
`server/src/services/gemini.ts` and `server/src/services/unifiedComparison/deepClauseValidator.ts` MUST:
- Derive the active generative model solely from `process.env.GEMINI_MODEL` (fallback: `gemini-3.7-flash`).
- Eliminate hardcoded references to deprecated or inconsistent models (`gemini-2.5-flash`, `gemini-3.5-flash`, `gemini-pro`, or `models/gemini-2.5-flash`).
- Provide consistent error logging when an API key or model name is not resolved.

### Requirement 3: Eliminación de Componentes Huérfanos del Frontend
The codebase MUST:
- Remove unused React components that have zero callers:
  - `components/AuditWizard.tsx`
  - `components/VariableComparisonMatrix.tsx`
  - `components/DeductibleSummaryTable.tsx`
- Ensure all relevant visual functionality is fully serviced by `components/UnifiedCoverageMatrix.tsx` and `components/AuditSection.tsx`.

### Requirement 4: Eliminación de Parsers de Deducibles Legacy y Código Muerto Backend
The codebase MUST:
- Remove `server/src/services/deductibleParser.ts` and its redundant test files (`deductibleParser.test.ts`, `deductibleParser.unit.test.ts`), which were superseded by `flatTableParser.ts` and `StructuredDeductible`.
- Clean obsolete diagnostic scripts in `server/src/scripts/` (`listGeminiModels.js`, `verify_gemini.ts`).

### Requirement 5: Supresión del Transformador Duplicado en el Frontend
`components/UnifiedCoverageMatrix.tsx` MUST:
- Remove the local 210-line implementation of `transformQuotesToMatrix`.
- Rely entirely on the backend-provided `rows: MatrixRow[]` generated by the unified comparison engine.
- Fall back gracefully to an empty state or loading skeleton if `rows` is not yet populated, rather than attempting to construct a fake PYME matrix in Hogar mode.

### Requirement 6: Depuración de Feature Flags Fantasma
`server/src/config/featureFlags.ts` MUST:
- Remove phantom flags that have zero consumer code: `deductibleSemanticParser`, `tripleSourceChat`, `queryExpansion`, `hybridSearchV2`.
- Keep active flags clearly documented with their rollback instructions.
